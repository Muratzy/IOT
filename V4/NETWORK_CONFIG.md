# V4 网络配置

## 网络拓扑

```text
网页 / CLI
     │ HTTP 8000
     ▼
电脑 Python 桥接服务（192.168.1.142）
     │ TCP 1000，经路由器 Wi-Fi/网线
     ▼
CH9121（192.168.1.200）
     │ USART1 9600 8N1
     ▼
STM32F401
```

电脑和 CH9121 必须处于同一个局域网。V4 真机测试使用 `192.168.1.0/24`。

## CH9121 已验证参数

### 基础设置

| 参数 | 数值 |
|---|---|
| 设备名称 | `CH9121` |
| 模块 MAC | `54:6C:50:30:C9:EF` |
| DHCP | 关闭 |
| 设备 IP | `192.168.1.200` |
| 子网掩码 | `255.255.255.0` |
| 网关 | `192.168.1.1` |

### 端口设置

| 参数 | 数值 |
|---|---|
| 网络模式 | `TCP CLIENT` |
| 本地端口 | 随机端口开启；固定值保留为 `2000` |
| 目标 IP | `192.168.1.142` |
| 目标端口 | `1000` |
| 串口波特率 | `9600` |
| 数据位 | `8` |
| 停止位 | `1` |
| 校验位 | 无校验 |
| 物理网线断开时关闭 Socket | 开启 |
| RX 打包长度 | `1024` |
| RX 打包超时 | `0` |
| 建立网络连接时清空串口数据 | 关闭 |

电脑 Wi-Fi 地址由路由器分配。地址不再是 `192.168.1.142` 时，需要同步修改 CH9121 的目标 IP，以及桥接脚本输出提示中的局域网地址。

## 电脑监听端口与接口

| 服务 | 地址 | 用途 |
|---|---|---|
| CH9121 TCP | `0.0.0.0:1000` | 接收状态帧并向 STM32 发送水泵命令 |
| 网页 | `0.0.0.0:8000/` | 实时数据显示和水泵控制 |
| 数据接口 | `GET /api/data` | 返回最新传感器、水泵及连接状态 JSON |
| 水泵接口 | `POST /api/pump` | 下发 PWM 占空比和运行时间 |

水泵接口请求示例：

```json
{
  "duty": 60,
  "duration_ms": 2000
}
```

- `duty` 必须为 `0~100` 的整数。
- `duration_ms` 最大为 `3600000`，即 1 小时。
- `duty=0` 时桥接和 STM32 都会把运行时间归零并立即关闭水泵。

## 启动顺序

1. 确认电脑已连接路由器 Wi-Fi，电脑地址为 CH9121 设置的目标 IP。
2. 在 `Host/` 启动 `python tcp_web_bridge_192.168.1.142.py`。
3. 确认控制台显示 TCP `1000` 和 HTTP `8000` 已监听。
4. 给 STM32 和 CH9121 上电，等待控制台显示模块连接地址。
5. 浏览器访问 <http://127.0.0.1:8000>。

连接失败时依次检查电脑 Wi-Fi 地址、CH9121 目标 IP、目标端口、防火墙和网线指示灯。
