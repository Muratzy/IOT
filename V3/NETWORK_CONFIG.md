# V3 网络配置

## 网络拓扑

```text
STM32F401
  │ USART1 9600 8N1
  ▼
CH9121 ──网线── 路由器 ──Wi-Fi── 电脑
                                  │
                                  ├─ TCP 1000：传感器数据入口
                                  └─ HTTP 8000：网页和本地 API
```

电脑和 CH9121 必须处于同一个局域网。V3 调试时使用 `192.168.1.0/24`。

## CH9121 已验证参数

### 基础设置

| 参数 | 数值 |
|---|---|
| 设备名称 | `CH9121` |
| 模块 MAC | `54:6C:50:30:C9:EF` |
| DHCP | 关闭 |
| 设备 IP | `192.168.1.200` |
| 子网掩码 | `255.255.255.0` |
| 网关 | `192.168.1.1` |

### 端口设置

| 参数 | 数值 |
|---|---|
| 网络模式 | `TCP CLIENT` |
| 本地端口 | 随机端口开启；固定值保留为 `2000` |
| 目标 IP | `192.168.1.142` |
| 目标端口 | `1000` |
| 串口波特率 | `9600` |
| 数据位 | `8` |
| 停止位 | `1` |
| 校验位 | 无校验 |
| 物理网线断开时关闭 Socket | 开启 |
| RX 打包长度 | `1024` |
| RX 打包超时 | `0` |
| 建立网络连接时清空串口数据 | 关闭 |

电脑当前 Wi-Fi 地址 `192.168.1.142` 由路由器分配。如果电脑地址发生变化，必须同步修改 CH9121 的目标 IP；也可以在路由器中为电脑 MAC `F8:3D:C6:0C:48:90` 设置固定 DHCP 租约。

## 上位机端口

| 服务 | 监听地址 | 用途 |
|---|---|---|
| CH9121 TCP 接收 | `0.0.0.0:1000` | 接收 STM32 串口透传帧 |
| 网页与 API | `0.0.0.0:8000` | 网页与 `/api/data` |
| CH9121 搜索 | 电脑 UDP `60000` → 模块 UDP `50000` | 搜索、读取和写入模块配置 |

## 配置工具看不到 Wi-Fi 网卡

旧版 `NetModuleConfig` 可能无法枚举 MediaTek 无线网卡。V3 调试时通过 CH9121 UDP 配置协议直接绑定 `192.168.1.142:60000`，向 `192.168.1.255:50000` 广播搜索报文，并将模块目标地址从旧的 `192.168.1.100:9000` 改为 `192.168.1.142:1000`。

## Windows 启动顺序

1. 确认电脑已连接路由器 Wi-Fi。
2. 启动 `Host/tcp_web_bridge_192.168.1.142.py`。
3. 确认控制台显示 `Listening on 0.0.0.0:1000`。
4. 给 STM32 和 CH9121 上电。
5. 浏览器访问 <http://127.0.0.1:8000>，或启动 CLI。

如果 TCP 未连接，依次检查电脑 Wi-Fi IP、CH9121 目标 IP、目标端口、防火墙和网线指示灯。
