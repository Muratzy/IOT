# 比赛当天速查

## 上电前

- 压力传感器必须处于零压，因为 `PRESSURE_Init()` 会把上电时的 ADC 平均值记为零点。
- 确认所有模块 GND 共地。
- 水泵驱动：PA6 接 PWM/IN1，PA7 接 IN2 并由程序保持低电平。
- CH9121 串口和 STM32 交叉连接：STM32 PA9(TX) -> 模块 RX，PA10(RX) <- 模块 TX。

## 最短启动流程

### 有线直连（不用路由器）

1. CH9121 网口直接电脑“以太网”。
2. 双击 `有线接收/启动有线直连.cmd`。
3. 允许管理员权限。
4. 看到 `[TCP] Connected: ('192.168.1.200', ...)` 表示网络通。
5. 网页会自动打开 `http://127.0.0.1:8000`。
6. 结束时点网页右上角“关闭服务”，以太网会恢复 DHCP。

### 无线（CH9121 接路由器，电脑连 Wi-Fi）

1. 电脑和 CH9121 连同一路由器。
2. 确认电脑地址是 CH9121 配置的目标 `192.168.1.142`。
3. 在 `04_上位机与调试/` 运行：

   ```powershell
   python tcp_web_bridge_192.168.1.142.py
   ```

4. 打开 `http://127.0.0.1:8000`。

## 30 秒检查链路

1. OLED 四行有 T1/T2、Flow、P、ADC/Delta。这一步不需要 CH9121。
2. Python 窗口出现 `[RX] T1=...`。这一步证明 STM32 -> 串口 -> CH9121 -> TCP 已通。
3. 访问 `http://127.0.0.1:8000/api/data`，能看到 JSON。这一步证明 Python 解析已通。
4. 网页显示与 OLED 大致一致。这一步证明前端已通。
5. 水泵先用 `1% / 1 s` 小参数测试，等待 `PUMP_ACK=1,TIME=1000,OK=1`。

## 出问题时先看哪里

| 现象 | 先查 |
|---|---|
| OLED 完全不亮 | I2C2 PB10/PB3、OLED 供电、`OLED_Init()` |
| OLED 正常，Python 没有 `[TCP] Connected` | 网络 IP、CH9121 TCP Client 目标、端口 1000 |
| 已 Connected，没有 `[RX]` | USART1 9600 8N1、TX/RX/GND |
| Python 有 `[RX]`，网页不动 | `/api/data`、端口 8000、浏览器缓存 |
| 流量一直 0 | PA0 脉冲、TIM2 外部时钟、`WATER_GetLastPulseCount()` |
| 压力不变 | PA1 电压、ADC 值 A、差值 D、零压重启 |
| 网页能发送但水泵不动 | ACK、PA6 PWM、PA7 低电平、驱动板供电 |
