# IOTCM 竞赛离线开卷资料

这个目录用于断网比赛现场。内容以当前真正运行的三部分为准：

- STM32 工程：`Lunar/`
- 无线上位机：`04_上位机与调试/`
- 电脑与 CH9121 网线直连：`有线接收/`

## 阅读顺序

| 文档 | 现场用途 |
|---|---|
| `00_比赛当天速查.md` | 从上电到网页出数据的最短流程 |
| `01_系统架构与硬件引脚.md` | 查数据链路、引脚、CubeMX 外设 |
| `02_STM32函数修改索引.md` | 知道“想改某个功能应该改哪个函数” |
| `03_传感器与OLED.md` | 温度、压力、流量、OLED 标定和显示 |
| `04_水泵PWM与定时控制.md` | 水泵占空比、运行时间、本地测试 |
| `05_串口和数据协议.md` | STM32、CH9121、Python 之间的帧格式 |
| `06_Python后端修改指南.md` | TCP 接收、解析、HTTP API、命令下发 |
| `07_网页前端修改指南.md` | 数据显示、图表、历史、水泵控制 |
| `08_有线与无线网络.md` | 路由器无线方案与网线直连方案切换 |

| `10_离线编译烧录与Git.md` | Keil 编译、HEX、回退、提交 |

## 三条现场原则

1. 先判断问题在 STM32、串口/CH9121、Python 还是网页，再改代码。
2. CubeMX 重新生成前，确保手写内容在 `USER CODE BEGIN/END` 之间；`Lunar/APP/` 中的独立库文件不会被 CubeMX 覆盖。
3. 每次只改一层，编译或运行确认后再改下一层。

## 当前稳定基线

- MCU：STM32F401RCT6，84 MHz。
- Keil 工程：`Lunar/MDK-ARM/Lunar.uvprojx`。
- HEX：`Lunar/MDK-ARM/Lunar/Lunar.hex`。
- 串口：USART1，9600 8N1，PA9 TX / PA10 RX。
- CH9121：TCP Client，`192.168.1.200 -> 192.168.1.142:1000`。
- 网页：`http://127.0.0.1:8000`。
- 水泵：PA6 / TIM3_CH1 PWM，PA7 始终为低，`0~100` 对应 `0%~100%`。
- 当前协议：v3 状态帧，包含两路温度、流量、压力和水泵状态。
