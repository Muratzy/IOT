## `main()` 的初始化顺序

```c
OLED_Init();
DS18B20_Init();
Delay_Init();
MOTOR_Init();
PRESSURE_Init();
WATER_Init();
NETWORK_Init(&huart1);
```

重要关系：

- `MOTOR_Init()` 在 `PRESSURE_Init()` 前，保证取压力零点时水泵处于关闭。
- `Delay_Init()` 打开 DWT 微秒时基，DS18B20 单总线时序需要它。
- `NETWORK_Init()` 会立即启动 USART1 单字节中断接收。

## `while (1)` 中的结构

```c
while (1)
{
    Temperature_Task();
    Pressure_Task();
    Water_Task();
    Pump_Task();

    PERIODIC_START(network_send, 250U)
        NETWORK_SensorFrame frame;
        /* 读取当前数值并发送 */
        (void)NETWORK_SendSensorData(&frame);
    PERIODIC_END;
}
```

这个 while 必须快速重复。不要在里面放 `HAL_Delay(2000)` 之类长阻塞，否则 OLED、传感器、串口命令和水泵定时都会停顿。

## `PERIODIC(T)` 怎么用

`PERIODIC(T)` 只能放在返回类型为 `void` 的任务函数中。时间未到时，它会 `return` 退出当前任务，不会阻塞 while 中的其他任务。

```c
static void My_Task(void)
{
    PERIODIC(100U);       /* 最多每 100 ms 执行一次 */
    /* 采集和更新 */
}
```

`PERIODIC_START/END` 适合在 `while` 中限制一块代码的频率：

```c
PERIODIC_START(upload, 250U)
    /* 这一块最多每 250 ms 执行一次 */
PERIODIC_END;
```

同一个函数内如果需要多个周期块，`NAME` 必须不同。

## 增加一个新传感器的步骤

1. 在 CubeMX 配好引脚和外设。
2. 在 `Lunar/APP/` 建 `SENSOR.c/.h`，提供 `Init/Update/Get/Status`。
3. 在 `main.c` 的 include 区引入头文件。
4. 在 `USER CODE BEGIN PFP` 声明 `static void Sensor_Task(void);`。
5. 在 `USER CODE BEGIN 0` 实现周期任务。
6. 在 `USER CODE BEGIN 2` 调用 `SENSOR_Init()`。
7. 在 while 调用 `Sensor_Task()`。
8. 如果要上网，扩展 `NETWORK_SensorFrame`、`NETWORK_SendSensorData()`、Python `latest/parse_frame()` 和前端 `render()`。

## 哪些地方不要随意改

- `Drivers/` 中的 HAL/CMSIS 源码。
- `startup_stm32f401xc.s`。
- CubeMX 生成函数中 `USER CODE` 之外的内容。
- `MOTOR_Slice()` 的状态判断，除非同时检查 `Pump_Task()` 的重复调用方式。
- `NETWORK_RX_LINE_SIZE=64`：扩展命令时要同时计算最长字符串。
