# 故障排查清单

排查顺序固定为：供电/接线 -> STM32 本地数据 -> USART -> CH9121/TCP -> Python/API -> 网页。不要在 OLED 已经错误时先改网页。

## OLED 不亮

1. 检查 3.3V/GND，确保没有异常抬高的“地”。
2. 检查 PB10=SCL、PB3=SDA，不要按常见 I2C 默认引脚猜测。
3. 检查 CubeMX I2C2 和 GPIO AF。
4. 检查 `OLED_I2C_ADDRESS (0x3C << 1)`。
5. 在 `OLED_Init()` 后临时写一行固定字符，排除任务逻辑：

   ```c
   OLED_ShowString(1, 1, "OLED TEST       ");
   ```

## 温度显示 WAIT

- 上电后短暂 WAIT 是正常的，DS18B20 转换需约 750 ms。
- 一直 WAIT：查 `Temperature_Task()` 是否持续调用，是否被长 `HAL_Delay` 卡住。
- 一直 ERR：查 4.7k 上拉、PB6/PB7、共地和供电。
- 偶发 CRC：缩短线、改善地线、确认 DWT 微秒时序。

## 流量一直 0

1. 用万用表/示波器看传感器 DATA 是否有脉冲。
2. 确认 DATA -> PA0，传感器 GND -> STM32 GND。
3. CubeMX：PA0 必须是 TIM2_CH1 外部时钟输入，而不是普通 GPIO。
4. 临时把 `WATER_GetLastPulseCount()` 显示在 OLED 或上传。
5. 脉冲数为 0：硬件/定时器问题。
6. 脉冲数非 0 但流量不对：查 `WATER_PULSES_PER_LITER=3433.8f`。
7. 值抖动大：适当增大 `WATER_FILTER_SAMPLES`，或检查传感器供电/脉冲质量。

## 压力一直 0 / ERR / 跳动

OLED 第 4 行是关键：`A` 是当前 ADC，`D` 是相对上电零点的差。

| 现象 | 判断 |
|---|---|
| `A:0000` 或固定不变 | PA1 没信号、接线错、模块坏或 ADC 配置错 |
| `ADC ERROR` | HAL ADC 启动/转换失败 |
| A 变，D 约几个计数 | 小幅噪声，Pa 数百到一千多跳动可能由此换算而来 |
| 抽水时 D 明显变 | 传感器有响应，再校准增益/量程 |
| 上电就有很大压力 | 建立零点时水路有压，停泵卸压后重启 |

本库使用 `abs(current-zero)`，所以传感器输出正向/反向都可以换算；方向看 D 的正负。

## 水泵不动

1. 网页最后命令是否显示“STM32 已确认”。
2. Python 窗口是否出现 `[TX] PUMP=...`。
3. 是否收到 `PUMP_ACK=...,OK=1`。
4. 后续状态帧 `M` 是否非 0，`MS` 是否为 1。
5. 用示波器看 PA6 PWM，检查 PA7 是低电平。
6. 检查驱动板大功率供电、共地和水泵接线。
7. 低占空比不动但高占空比能动，可能是水泵启动阈值，不是 PWM 映射错。

## 水泵不会自动停

- 检查 while 中 `Pump_Task()` 是否一直调用。
- 检查是否每圈都调了 `MOTOR_SliceReset()`；Reset 只能在收到新命令时调用。
- 检查是否使用 `MOTOR_SetDuty()` 代替了 `MOTOR_Slice()`。`SetDuty` 不自动停。
- 检查 `HAL_GetTick()` 是否正常增长。

## Python 显示已连接但没数据

1. 查 STM32 OLED 是否刷新。
2. 查 STM32 USART1 TX -> CH9121 RX。
3. 查波特率 9600 8N1。
4. 看 Python 是否偶尔出现不完整字符串或 `0000`。单独的碎片常与串口干扰、复位或 CH9121 打包设置有关。
5. 只要完整帧持续到达，Python 会丢弃无法解析的单行并继续。

## 网页没数据，Python 有 `[RX]`

1. 打开 `http://127.0.0.1:8000/api/data`。
2. API 有正常 JSON：问题在 `dashboard.html` JavaScript，打开 F12 Console。
3. API 404：路径或 Python `Handler.do_GET()` 被修改。
4. API 连不上：后端没运行、端口不对或旧进程占用。
5. 强制刷新 Ctrl+F5。

## 网页下发失败

- HTTP 409 / `CH9121 未连接`：后端没有 `active_client`。
- HTTP 400：检查 JSON 是否包含整数 `duty` 和 `duration_ms`。
- HTTP 200 但没 ACK：查 CH9121 -> STM32 RX 方向和 USART1 中断。
- ACK=0：查实际字符串是否严格为 `PUMP=n,TIME=n\r\n`。

## 端口被占用

```powershell
Get-NetTCPConnection -State Listen -LocalPort 1000,8000 -ErrorAction SilentlyContinue
```

先用原网页右上角“关闭服务”。不要盲目杀所有 Python 进程，可能会影响其他程序。
