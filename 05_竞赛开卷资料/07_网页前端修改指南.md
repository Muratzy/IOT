# 网页前端修改指南

## 文件特点

`04_上位机与调试/dashboard.html` 是单文件前端，HTML、CSS、JavaScript 都在同一文件中。不依赖 npm、CDN 或互联网，适合断网运行。

## 函数映射

| 想改的功能 | 位置 |
|---|---|
| 状态码中文 | `statusText` |
| 状态徽标样式 | `setBadge()` 和 `.badge` CSS |
| 数值小数位 | `sensorValue()` 的 `digits` 参数 |
| 在线/离线判断 | `updateConnection()` |
| 温度、流量、压力显示 | `render(data)` |
| 水泵实际状态 | `renderPumpState(data)` |
| 数据轮询 | `refresh()` |
| 轮询间隔 | 文件底部 `setInterval(refresh, 250)` |
| 历史库 | `openHistory()`，IndexedDB 名 `iotcm-v3-history` |
| 保存一帧 | `rememberFrame()` |
| 图表数据 | `readChartSamples()` / `refreshCharts()` |
| 图表绘制 | `paintCharts()` 和其子函数 |
| CSV 导出 | `exportHistory()` |
| 占空比滑块 | `setPumpDuty()` |
| 发水泵命令 | `sendPumpCommand()` |
| 关闭 Python 服务 | `serviceStop` 的 click 处理 |

## 数据刷新逻辑

`refresh()` 每 250 ms 请求 `/api/data`：

```javascript
const response = await fetch("/api/data", { cache: "no-store" });
const data = await response.json();
render(data);
await rememberFrame(data);
```

- `render()` 更新当前数值。
- `rememberFrame()` 只保存新帧，避免 250 ms 轮询把同一帧重复存储。
- 图表默认每 2 秒从本地历史库重新取样。
- API 不可用时会显示“本地服务不可用”。

## 增加一张数据卡片

1. 在 HTML 的 `.measurements` 区增加 `<article class="card">`。
2. 给数值和状态元素分配唯一 `id`。
3. 在 `render(data)` 中用 `el("id").textContent = ...` 更新。
4. 如果有状态，调 `setBadge("badgeId", data.xxx_status)`。
5. 如果要进入历史/图表，同步改 `rememberFrame()`、IndexedDB 样本结构、表格和绘图函数。

## 改压力显示单位

当前主数值用 Pa，辅助文字用 MPa。修改时在 `render(data)` 处理，后端仍同时提供 `pressure_pa` 和 `pressure_mpa`。

```javascript
const kpa = Number(data.pressure_pa) / 1000;
el("pressure").textContent = kpa.toFixed(2);
```

记得同步修改单位文字、图表标签和 CSV 表头。

## 水泵控制

`sendPumpCommand()` 做了三件事：

1. 读取滑块的 duty 和输入框的秒数。
2. 把秒换算成 `duration_ms`。
3. POST JSON 到 `/api/pump`。

```javascript
body: JSON.stringify({ duty, duration_ms: durationMs })
```

“立即关闭”会强制 `duty=0,duration_ms=0`。如果改控件 ID，必须同步修改底部 `addEventListener()` 绑定。

## 历史数据在哪里

- 历史数据存在浏览器 IndexedDB，不是 Python 文件。
- 换浏览器、清理网站数据或更换 origin 可能看不到原历史。
- IndexedDB 不可用时退化为页面内存，刷新即丢失。
- 比赛需留档时及时使用“导出 CSV”。

## 离线调试

1. 修改后不要直接双击 HTML，要由 Python 服务打开 `http://127.0.0.1:8000`，否则 `/api/data` 相对路径没有后端。
2. F12 -> Console 查 JavaScript 报错。
3. F12 -> Network 查 `/api/data` 和 `/api/pump`。
4. 先直接打开 `/api/data`确定 JSON 有字段，再怀疑 `render()`。

## 不要破坏的安全点

- 关闭接口必须带 `X-IOTCM-Action: shutdown`。
- 水泵按钮发送期间应禁用，避免快速重复点击。
- 页面上显示的“实际 PWM”要来自状态帧 `pump_duty`，不能只显示滑块设定值。
